# HCI \& Computer Graphics

Coursework and design resources for Human–Computer Interaction (HCI) and
Computer Graphics. The repository contains Figma design files, supporting
visual exports, and reference material for design practice and study.

### Projects

The `projects/` directory contains larger or quiz-related design work,
including the QuickReview HCI quiz project.

### Tasks

The `tasks/` directory organizes submitted design exercises by task number.
Figma source files are preserved alongside exported visual assets where
available.

### Resources

[`resources\\\_for\\\_HCI.md`](resources_for_HCI.md) lists references for Figma,
design fundamentals, prototyping, design systems, UX principles, and common
platform design guidelines.

## Opening the Design Files

Files with the `.fig` extension are Figma design files. To view or edit them:

1. Open [Figma](https://www.figma.com/).
2. Import the required `.fig` file using **File → Import**.
3. Review or edit the imported document.

PNG files can be opened directly in any image viewer and are included as
visual references or exported design assets.

## Working with the Repository

Keep source design files in their existing project or task directory. When
exporting additional assets, use descriptive filenames and place them beside
the related Figma file. Avoid replacing the original source file unless the
change is intentional; create a clearly named revision when preserving
multiple versions is important.

## Notes

* The `.fig` files are source artifacts rather than text-based source code.
* File names retain the associated coursework identifiers for traceability.
* This repository does not currently include an application build, package
manager configuration, or automated test suite.
